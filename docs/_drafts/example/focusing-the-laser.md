# Focusing the laser (wood, acrylic and other organic materials)

> Source: https://fslaser.com/static/files/resources/manuals/mc-series-co2-flatbed-manual.pdf, p. 23, Focusing; p. 25, Control Panel · Retrieved 2026-11-12
> REVIEW: A focus ruler is mentioned but the source does not explain how to use it.

Use the 4mm focus wedge to set the nozzle height above the material before cutting organic materials.

## Steps

1. Staff: make sure the 4" (100mm) lens is installed in the upper slot for cutting organic materials. {staff_only: true}
2. Use Z+/Z- to raise and lower the cutting head. This works while the machine is in Acrylic Mode.
   REVIEW: The source does not explain 'Acrylic Mode'. It appears to be the right-side switch setting opposite to 'Metal'.
3. Jog the Z axis down until the focus wedge fits snugly between the material and the nozzle.

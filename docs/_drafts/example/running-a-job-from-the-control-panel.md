# Running a job from the control panel

> Source: https://fslaser.com/static/files/resources/manuals/mc-series-co2-flatbed-manual.pdf, pp. 24-25, Section V. Control Panel · Retrieved 2026-11-12
> REVIEW: The source only lists what each button does. The step order is inferred and should be checked against local practice.
> REVIEW: Focusing is covered in a separate doc and should be done before starting.
> REVIEW: Reset re-homes the machine and Menu opens settings. Staff may want to restrict Menu.

The control panel lets you load, position, frame, start, pause and stop a job without a computer.

## Steps

1. Press File to choose a job file from memory or USB.
2. Use X+/X- and Y+/Y- to move the laser head and gantry into position.
3. Press Origin to set the starting position for the job.
4. Press Frame to trace the outline of the job and check it fits the material.
5. Press Start-Pause to start or pause the job.
6. Press Stop to stop and reset the job.

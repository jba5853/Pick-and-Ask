# Preparing a file in MetalCut

> Source: https://fslaser.com/static/files/resources/manuals/mc-series-co2-flatbed-manual.pdf, p. 19, MetalCut Installation; pp. 26-27, Section VI. MetalCut · Retrieved 2026-11-12
> REVIEW: The source only lists toolbar functions. The step order is inferred.
> REVIEW: The source does not explain how to send a job from MetalCut to the laser.

MetalCut is the software used to import, check, preview and save job files for this laser.

## Steps

1. Open MetalCut from the computer desktop.
2. Use Import to bring a compatible file into the workspace.
   REVIEW: The source does not list which file types are compatible.
3. Use Data Check to look for problems in the vector drawing.
4. Use Preview to simulate cutting the job.
5. Save your workspace as an RLD file.

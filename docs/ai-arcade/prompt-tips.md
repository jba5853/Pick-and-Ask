# Prompt tips

> Sources: https://sites.psu.edu/aiarcade/a001/, https://sites.psu.edu/aiarcade/a002, https://sites.psu.edu/aiarcade/a005, https://sites.psu.edu/aiarcade/a006 · Retrieved 2026-10-28

General tips for writing better prompts in any AI Arcade tool, taken from the activities.

- **Describe the feeling, not just the subject.** For music, say the mood, genre, instruments and emotion you want.
- **Add a style or emotion.** Asking for a specific style, like a pop song or a sea shanty, gives a more distinctive result.
- **Add constraints.** Limits such as "use only simple words" or "no characters" make you work within boundaries, which can make the result more creative.
- **Use a fill-in-the-blanks template.** Name the place or subject, the style, the key details and the mood, in that order.
- **Ask ChatGPT for help.** If you're stuck, ask ChatGPT to suggest visual ideas or to write an image prompt for you, then paste it into the other tool.
